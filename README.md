# UI/UX Track Roadmap

The learning plan for the UI/UX track. One roadmap covers both levels, Beginner and Intermediate.

## What is in this repository

- `UI-UX-Track-Roadmap.md`: the week-by-week roadmap. Open it first.
- `README.md`: this file.

## Who it is for

- **Beginners:** new or still developing in UI/UX. You get guided tasks, templates, and more mentor checkpoints.
- **Intermediates:** you already have hands-on practice. You answer the same task questions, but you must justify your decisions with evidence and alternatives.

Both levels follow the same sessions and build toward the same team final project, so everyone ends the season at a similar level.

## How to use it

1. Open `UI-UX-Track-Roadmap.md` and find the current week.
2. Study the **Core** materials. Intermediates also use the **Deep Dive** materials.
3. Do the weekly task for your level and bring it to the session.
4. In every session, one screen gets a 15-minute group critique.
5. After the 15 sessions (Weeks 16 to 20), the team Final Project starts (research, wireframes, final UI, prototype, case study).
